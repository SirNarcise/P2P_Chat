================================================================
  P2P ЗАЩИЩЁННЫЙ ЧАТ — ИНСТРУКЦИЯ ПО УСТАНОВКЕ
  Linux / macOS / Windows
================================================================

ЧТО ЭТО
-------
Консольная программа для приватной переписки напрямую между
двумя пользователями (без серверов-посредников). Сообщения и
файлы шифруются AES-256-GCM. Соединение возможно только при
совпадении общего кодового слова, которое вы придумали заранее.

ФАЙЛЫ ПРОГРАММЫ
---------------
  p2p_chat.py             — основной файл программы
  instruction.txt             — этот файл с инструкцией

Создаваемые программой файлы (в домашней папке):
  ~/.p2p_chat_identity        — ваша постоянная идентичность
                                (приватный ключ, можно копировать
                                на другие устройства)
  ~/.p2p_chat_known_keys      — доверенные отпечатки собеседников


================================================================
1. УСТАНОВКА PYTHON
================================================================

Программе нужен Python 3.8 или новее.
Проверить версию:

  python3 --version     (Linux/macOS)
  python --version      (Windows)

--- Linux (Ubuntu / Debian / Mint) ---
  sudo apt update
  sudo apt install python3 python3-pip

--- Linux (Fedora / RHEL) ---
  sudo dnf install python3 python3-pip

--- Linux (Arch) ---
  sudo pacman -S python python-pip

--- macOS ---
  Python 3 обычно уже установлен. Если нет:
    brew install python
  Если Homebrew не установлен, скачайте с https://brew.sh

--- Windows ---
  1. Скачайте Python с https://www.python.org/downloads/
  2. При установке ОБЯЗАТЕЛЬНО отметьте галочку
     "Add Python to PATH".
  3. Проверьте в командной строке:
     python --version


================================================================
2. УСТАНОВКА ЗАВИСИМОСТЕЙ
================================================================

Нужна библиотека cryptography.

--- Linux / macOS ---
  python3 -m pip install cryptography

  Если ошибка про "externally-managed-environment",
  используйте виртуальное окружение (рекомендуется):

    python3 -m venv venv
    source venv/bin/activate
    pip install cryptography

--- Windows (cmd) ---
  python -m pip install cryptography

--- Windows (PowerShell) ---
  python -m pip install cryptography

ОПЦИОНАЛЬНО: Argon2 для более стойкого KDF пароля
--- Linux / macOS ---
  python3 -m pip install argon2-cffi
--- Windows ---
  python -m pip install argon2-cffi

Если Argon2 не установлен — программа автоматически использует
PBKDF2-HMAC-SHA256 (200 000 итераций). Тоже безопасно.


================================================================
3. ПОДГОТОВКА К РАБОТЕ
================================================================

ШАГ 1. Придумайте общее кодовое слово
  Это может быть любая фраза, известная только вам двоим:
    "кофе с корицей в три ночи"
    "правильный ответ — 42"
    "стихотворение из детства"
  Минимум 8 символов. Чем длиннее и менее очевидно — тем лучше.
  НЕ передавайте его через тот же канал, по которому будете
  общаться. Договоритесь лично, по телефону или через Signal.

ШАГ 2. Узнайте свой локальный IP (нужен собеседнику)
--- Linux ---
  ip addr | grep inet
  или: hostname -I
--- macOS ---
  ifconfig | grep inet
  или: ipconfig getifaddr en0
--- Windows ---
  ipconfig
  Ищите строку "IPv4 Address".

ШАГ 3. Откройте порт в брандмауэре (если нужно)
По умолчанию программа использует порт 5555 (можно любой).
--- Linux (ufw) ---
  sudo ufw allow 5555/tcp
--- Windows ---
  Панель управления → Брандмауэр → Дополнительные параметры →
  Правила для входящих подключений → Создать правило →
  Порт → TCP → 5555 → Разрешить.


================================================================
4. ЗАПУСК
================================================================

ВАЖНО: обе стороны должны ввести ОДИНАКОВОЕ кодовое слово.
Если слова разные — соединение прервётся сразу после рукопожатия.

--- Сторона А (тот, кто "слушает") ---
  python3 p2p_chat.py --listen --login alice --port 5555

  Программа спросит:
    Введите общее кодовое слово (мин. 8 символов): ********
    Повторите: ********

  Дальше будет ждать подключения.

--- Сторона Б (тот, кто "подключается") ---
  python3 p2p_chat.py --connect --login bob --peer 192.168.1.10:5555

  Где 192.168.1.10 — IP стороны А, 5555 — её порт.
  Тоже спросит кодовое слово.

--- Windows: замените python3 на python ---
  python p2p_chat.py --listen --login alice --port 5555


================================================================
5. ПЕРВОЕ СОЕДИНЕНИЕ
================================================================

При первом подключении программа покажет отпечаток ключа
собеседника:

  [*] Первое подключение к 'bob'
  [*] Отпечаток публичного ключа: 3f8a:12b7:9c4d:e5f6:...
  Доверять этому отпечатку? (yes/no):

Сверьте отпечаток с собеседником через ДРУГОЙ канал (голосом,
по телефону). Если совпадает — введите "yes". С этого момента
отпечаток запомнится.

При следующих подключениях:
  - если отпечаток совпадает — соединение сразу
  - если изменился — будет громкое предупреждение о возможном
    "человеке посередине". Разберитесь, прежде чем продолжать.


================================================================
6. ИСПОЛЬЗОВАНИЕ ЧАТА
================================================================

  > Привет!                  — обычное сообщение
  > /file /путь/к/файлу      — отправить файл
  > /quit                    — выйти

Получатель файла увидит:
  [📎] bob хочет отправить файл:
      Имя:    photo.jpg
      Размер: 2456789 байт (2399.2 KiB)
      SHA-256: 8f4e3c2a1b0d...
  Принять? (y/n):

После сохранения файл кладётся в текущую директорию.
Если файл с таким именем есть — добавляется (1), (2) и т.д.


================================================================
7. ОПЦИЯ --pad: скрыть размер сообщений
================================================================

По умолчанию программа отправляет сообщения переменной длины —
по трафику можно косвенно угадать, что ты пишешь (например,
короткое "да" или длинное сообщение).

С флагом --pad все кадры дополняются до 1024 байт и отправляются
со случайной задержкой 0–150 мс. Атакующий не сможет
анализировать ни размер, ни тайминги.

--- Запуск с паддингом ---
  python3 p2p_chat.py --listen  --login alice --port 5555 --pad
  python3 p2p_chat.py --connect --login bob --peer IP:5555  --pad

ВАЖНО: обе стороны должны использовать одинаковый флаг --pad.
Если один включил, а другой нет — соединение не установится.


================================================================
8. РАБОТА С НЕСКОЛЬКИХ УСТРОЙСТВ
================================================================

У каждого пользователя есть постоянная идентичность —
файл ~/.p2p_chat_identity с приватным ключом. Он генерируется
автоматически при первом запуске.

Чтобы работать с другого устройства под тем же логином:
  1. Скопируйте файл ~/.p2p_chat_identity на другое устройство
     в ту же домашнюю папку.
  2. Запустите программу с тем же --login.
  3. Для собеседника вы останетесь тем же пользователем.

СПОСОБЫ ПЕРЕНОСА ФАЙЛА:
  - USB-флешка (безопасно)
  - Зашифрованный архив (7z с паролем, gpg)
  - Локальная сеть (scp, sftp)

НЕ ПЕРЕНОСИТЕ файл через публичные каналы:
  - Telegram, WhatsApp, email, облака без шифрования
  Этот файл = ваш приватный ключ. Если он утечёт — атакующий
  сможет выдать себя за вас.

Где лежит файл:
  Linux/macOS: /home/<user>/.p2p_chat_identity
  Windows:     C:\Users\<user>\.p2p_chat_identity


================================================================
9. ЧАСТЫЕ ВОПРОСЫ
================================================================

Q: Программа пишет "Проверка кодового слова не удалась".
A: Вы с собеседником ввели разные слова. Договоритесь и
   запустите заново.

Q: "[!!] Отпечаток изменился".
A: Собеседник пересоздал идентичность (удалил файл) или
   это MITM-атака. Уточните у собеседника, что произошло,
   сверьте отпечаток голосом.

Q: Не подключается, "Connection refused".
A: Сторона А не запущена, либо порт закрыт брандмауэром,
   либо указан неверный IP.

Q: Не подключается через интернет (не локальную сеть).
A: Нужен проброс порта на роутере или VPN. Программа работает
   только в локальной сети или при наличии публичного IP.

Q: Файл не передаётся, "Тайм-аут ожидания согласия".
A: Собеседник не ответил "y" в течение 5 минут. Попробуйте снова.

Q: "[!] Хеш не совпал!".
A: Файл повреждён при передаче или подменён. Передайте снова.


================================================================
10. БЕЗОПАСНОСТЬ — ЧТО ЗАЩИЩЕНО
================================================================

Защищено:
  ✓ Содержимое сообщений (AES-256-GCM)
  ✓ Содержимое файлов (AES-256-GCM)
  ✓ От подмены пакетов (GCM-тег)
  ✓ От повторов (уникальный nonce на сообщение)
  ✓ От MITM при первом контакте (кодовое слово)
  ✓ От MITM при повторных (отпечатки ключей)
  ✓ От подмены личности (Ed25519-подписи)
  ✓ От анализа размера/времени (с --pad)

Не защищено:
  ✗ Метаданные: факт соединения, объём трафика, время
  ✗ Слабый пароль: если кодовое слово "123" — переберут
  ✗ Компрометация устройства: если у вас троян — он увидит всё
  ✗ Утечка ~/.p2p_chat_identity — атакующий станет вами


================================================================
11. УДАЛЕНИЕ ПРОГРАММЫ
================================================================

Программа не устанавливается в систему — это просто скрипт.

Чтобы удалить все следы:
--- Linux / macOS ---
  rm -f ~/.p2p_chat_identity
  rm -f ~/.p2p_chat_known_keys
  rm -f p2p_chat.py
  rm -rf venv   (если создавали)
--- Windows ---
  del %USERPROFILE%\.p2p_chat_identity
  del %USERPROFILE%\.p2p_chat_known_keys
  del p2p_chat.py

Библиотеку cryptography можно удалить командой:
  python3 -m pip uninstall cryptography
